# Research and AI Use Log

## AI assistance

This project was built with assistance from OpenAI Codex. It was used to help plan the FastAPI/SQLite data model, implement the load-management rules and review the required walkthrough scenario. All final code and behavior were reviewed in the local project.

## Web and search activity

No Google searches, web searches, or copied third-party code were used for the application implementation.

The only external repository checks performed were attempts to access the project repository at `https://github.com/Rakshanayak24/Hackathon` to verify the remote configuration. One browser fetch returned a cache miss and one Git remote check could not connect; neither supplied implementation content.

## Dependency downloads

`pip` downloaded the Python packages listed in `requirements.txt`. `npm` downloaded the declared local frontend dependencies: React, React DOM, and Vite. These dependencies are declared in `frontend/package.json` and locked in `frontend/package-lock.json`.
